# 严格按时间戳排序的侧栏关注分界线

[English](2026-09-08-sidebar-attention-divider.md) | 中文

状态：隔离候选，尚未部署。

## 决策

办公室用户明确选择严格按 `updatedAt` 排序，而不是手动编辑会话顺序。会话目录通过 `useSessions` 提供权威数据；分界点是注册在工作区存储中的浏览器查看状态，通过 `useStore` 读取、通过 `actions.setAttentionCutoff` 写入。比截止时间新的会话在线上，旧的在线下。时间戳相同时，可选的会话 ID 和 before/after 方位在既有 ID 升序中定位精确间隙。新活动通过更新时间重新分类会话，不维护成员清单。删除分界锚点不会改变这一时间戳与身份排序规则。

新的浏览器查看存储默认使用单列表，让用户无需切换模式就能发现原生关注线。既有工作区分组偏好不会被覆盖。单列表渲染一条原生分界线。分组视图保留工作区排序与折叠，组内会话按时间戳排序，并提供明确的「切到时间列表使用关注线」入口，而不是在互相独立的分组之间画一条误导性的全局线。该入口使用独立的 32px 边框按钮，配以主要文字、半粗字重、浅色背景和可见键盘焦点，与低强调度的翻页控件区分。搜索结果不显示分界线。这部分取代了[工作区侧栏排序与折叠](implemented/feature/2026-08-11-workspace-sidebar-order-and-folding.zh.md)中的会话排序决策；Host 账户和工作区折叠决策保持不变。这个尚未发布的办公室候选不归档历史记录。

## 交互与持久化

分界线占据真正的 32px CSS Grid 行，而不是覆盖会话行边缘。FlatList 拥有唯一的临时预览，将分界线和会话包装节点置于不同网格行。手柄在整个手势中始终是同一个 DOM 子节点，只改变网格位置，因此保留指针捕获。命中测试从指针坐标和行中点坐标中扣除测得的预留行，避免移动的间隙反复改变自身目标。取消会恢复已保存的位置，并保留相邻会话的点击区域。只有 28×20 手柄接管 450ms 指针长按；右边缘与会话时间列共同使用 8px 内缩，不显示「关注/可忽略」说明。会话行保留点击、菜单和悬停行为，禁用会话的原生拖动。激活前移动、指针取消、捕获丢失、Escape、窗口失焦、区域外释放、组件销毁和目录时间戳变化均取消手势而不提交。边缘滚动只作用于现有列表容器，目录翻页仍由现有滚动处理器负责。仅在尾部追加的翻页保留手势、捕获和预览，前提是此前观察到的完整前缀在每个位置上都保留相同 ID 与时间戳；移动时读取新行几何信息，可以定位到新页。每个接受的页面都会扩展受保护前缀，之后即使删除或修改刚追加的行也会取消手势。目录更新和手势事件中都会重新核对，包括 pointerup；effect 清理仅用于销毁，不用于翻页。发生移动的手势在 pointerup 时只提交一次。键盘方向键、Home 和 End 提供等价的显式分界点移动。

分界点仅属于当前浏览器与来源，不跨设备同步。首次使用或缺失旧状态时，使用挂载时的当前时间初始化并仅持久化一次，让较早会话位于线下。有效的旧数字分界点保持原意。分界点早于已加载目录时仍保留，并显示翻页说明；加载更多不会重置它。代码回滚不删除查看状态，也不更改会话。完整的上一版 `client-lib` 是回滚单位；候选只改变浏览器 JS/map。

## 验证

将基线原生浏览器构建与生产 source map 和生成的 JavaScript 比较，保留已部署的翻页、滚动与搜索行为。组合后的侧栏没有可工作的首条提示加载器：运行时 API 与列表元数据都未实现该能力。移除无效注入、必填属性和不受支持的元数据读取，使浏览器与该 ABI 一致，不改变显示标题，也不虚构 API。可选的行级显示辅助函数保持不变；此变更不声称支持首条提示。聚焦测试覆盖分界投影、相同时间戳、持久化、指针归属、取消和边缘滚动，并更新工作区浏览器行为测试。独立的隔离浏览器可以在既有 3080 URL 仅替换候选 JavaScript；这是候选验证，不是生产激活。激活与原 URL 生产验收仍由协调父代理负责。

本候选仅按时间排序的产品规则由[侧栏手动排序与独立灰线](implemented/feature/2026-09-09-sidebar-attention-manual-restore.zh.md)撤销。最近更新模式的分界点、活动提升和分界线呈现保持不变。
